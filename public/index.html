Production Design Specifications
  • Scale: 100k daily consultations supported via Aurora PostgreSQL range partitioning.
  • Double-Booking Protection: Redis Redlock mutex + atomic SQL optimistic row updates (`version`).
  • Write Idempotency: `Idempotency-Key` header prevents duplicate billing and bookings.
  • PHI Protection: Field-level AES-256-GCM encryption for all clinical data.
  • Resilient Workers: BullMQ queue with exponential backoff & Dead Letter Queue (DLQ).
  • Observability: Structured JSON logging via Pino with correlation IDs (`X-Request-Id`).
